# Deutsch A2

App personal para estudiar alemán (nivel A2). Se instala como app (PWA) y anda sin internet.

El contenido del curso está cifrado y solo se desbloquea con la cuenta de su dueño. Este repositorio tiene el código de la app y los archivos cifrados.

Incluye software de terceros con licencia Apache 2.0: Firebase JS SDK, vosk-browser y el modelo de voz vosk-model-small-de-0.15 de Alpha Cephei. Ver [vendor/](vendor/README.md).
